# Localization instructions (language-model pass)

## Goal

Translate the English placeholder strings in the 20 non-English UI locales so
the guided tour (and one STT label) read natively. English (`en.json`) is the
source of truth and must not change.

## Background you need

- UI language resolution (`src/renderer/src/lib/i18n.ts`): the `uiLanguage`
  setting defaults to `auto`, which resolves from the OS locale
  (`navigator.language`, first two letters). Unsupported codes fall back to
  English. Only these 21 codes exist: `ar da de es fa fi fr he hi id it ja ko
  nl pl pt ru sv tr zh` (`zh` = Simplified Chinese).
- Locale files: `src/renderer/src/locales/<code>.json` (flat key → string).
  Missing keys fall back to English at runtime, but
  `tests/i18n.test.ts` enforces **full key parity**: every file must contain
  exactly the same keys as `en.json` (currently 500 keys).
- Files are generated by `scripts/gen-locales.mjs` (`pnpm gen:locales`):
  `ENTRIES` = `[desktopKey, androidKey, english]` rows; `SUPPLEMENTAL` =
  hand-written per-locale overrides that survive regeneration. **Anything you
  put directly in `locales/*.json` will be wiped by the next generator run.**
  Therefore: write your translations into `SUPPLEMENTAL` (see below), not
  into the JSON files.

## What to translate (119 keys, currently English copies)

All keys below exist in every locale file with English text. Translate the
values; listed by area in suggested working order:

1. Dialogs + safety (most visible): `tour.skipConfirmTitle`,
   `tour.skipConfirmBody`, `tour.safety.title`, `tour.safety.body`,
   `tour.safety.bullet1`, `tour.safety.bullet2`
2. Chat + tools + LLM: `tour.modes.conversation|corrective|immersive|
   reflective.*`, `tour.lang.helper|learn|flip.*`, `tour.tool.glossary|
   select|save|granular|speak|translit.*`, `tour.tts.*`, `tour.llm.intro|
   provider|apikey|baseurl|model|maxtokens|temperature|enable|done.*`
   (each `.*` = `.title` + `.body`)
3. Sessions + engines + themes: `tour.sessions.*`, `tour.new.session.*`,
   `tour.drawers.done.*`, `tour.ext.intro|deepl|google|picker|toggle|done.*`,
   `tour.themes.button|menu|done.*`
4. Review/Reader/Scenarios/Lexicon: `tour.srs.intro|page|flip|drawer|done.*`,
   `tour.reader.intro|topbar|gloss|tools|lock|done.*`, `tour.scenarios.intro|
   grid|filter|card|done.*`, `tour.lex.intro|page.*`,
   `tour.langdex.open|search|done.*`
5. Misc: `settings.stt.sizeMb` (mirrors `settings.tts.sizeMb`, e.g. `"{1} MB"`)

## Rules (strict)

1. **Values only.** Never rename, add, or delete keys. Never touch `en.json`,
   `src/renderer/src/lib/i18n.ts`, `UI_LANGUAGE_CODES`, or any `.ts/.tsx`
   logic.
2. **Keep placeholders verbatim.** `{1}`, `{2}` must appear unchanged in every
   translation (position may move to fit grammar).
3. **Plain text only.** No HTML, Markdown, or links. Keep emoji only where the
   English source has it (none in the new keys).
4. **Match the source register:** titles are short noun phrases; bodies are
   one-to-two friendly sentences, second person, same information content —
   do not add features or steps that are not described.
5. **`zh` is Simplified Chinese.** `pt` follows the existing files (Brazilian
   leaning: `lang.pt` maps to Android `lang_pt_br`).
6. **RTL (`ar`, `fa`, `he`)**: translate normally; layout direction is
   automatic — do not insert direction marks.
7. Write translations into `SUPPLEMENTAL` in `scripts/gen-locales.mjs` as
   `'key': { ar: '…', da: '…', … }` entries (one line per key, all 20 codes),
   then run `pnpm gen:locales` to regenerate. Do not edit `locales/*.json`
   by hand.

## Verify when done

1. `pnpm gen:locales` — regenerates all 21 files from your `SUPPLEMENTAL`.
2. `npx vitest run tests/i18n.test.ts` — parity + spot-translation checks.
3. `npx vitest run` (full) and `npx tsc --noEmit -p tsconfig.web.json`.
4. Spot-check in-app: set UI language (Settings → Interface), start the tour
   (Settings → Take the tour), walk several steps; confirm no English remains
   for that language and no raw `tour.*` keys appear. Repeat for one RTL
   language (`ar`) to confirm layout.
